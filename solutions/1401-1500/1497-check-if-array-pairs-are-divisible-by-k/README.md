# 1497. Check If Array Pairs Are Divisible by K

[LeetCode problem 1497](https://leetcode.com/problems/check-if-array-pairs-are-divisible-by-k/)

- **Difficulty**: medium
- **Tags**: array, hash-table, counting

## Description

Given an array of integers `arr` of even length `n` and an integer `k`,
return `true` if it is possible to divide `arr` into `n / 2` pairs such
that the sum of each pair is divisible by `k`.

Constraints: `arr.length` is even, `1 <= arr.length <= 10^5`,
`1 <= k <= 10^5`.
