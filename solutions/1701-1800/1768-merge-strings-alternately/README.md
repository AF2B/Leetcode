# 1768. Merge Strings Alternately

[LeetCode problem 1768](https://leetcode.com/problems/merge-strings-alternately/)

- **Difficulty**: easy
- **Tags**: string, two-pointers

## Description

Given two strings `word1` and `word2`, merge them by adding letters in
alternating order, starting with `word1`. If one string is longer, append
its remaining letters at the end.

Constraints: `1 <= word1.length, word2.length <= 100`.
