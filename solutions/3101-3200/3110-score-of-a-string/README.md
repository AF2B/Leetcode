# 3110. Score of a String

[LeetCode problem 3110](https://leetcode.com/problems/score-of-a-string/)

- **Difficulty**: easy
- **Tags**: string

## Description

The score of a string is defined as the sum of the absolute difference
between the ASCII values of adjacent characters. Return the score of `s`.

Constraints: `2 <= s.length <= 100`, `s` consists of lowercase English
letters.
