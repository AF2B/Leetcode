# 27. Remove Element

[LeetCode problem 27](https://leetcode.com/problems/remove-element/)

- **Difficulty**: Easy
- **Tags**: array, two-pointers

## Description

Given an array `nums` and a value `val`, remove all occurrences of `val` in
place and return the number of remaining elements `k`; the first `k`
elements of `nums` must hold the result, in any order.
