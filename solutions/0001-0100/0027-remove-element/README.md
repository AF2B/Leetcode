# 27. Remove Element

[LeetCode problem 27](https://leetcode.com/problems/remove-element/)

- **Difficulty**: easy
- **Tags**: array, two-pointers

## Description

Given an array `nums` and a value `val`, remove all occurrences of `val`,
keeping the relative order of the remaining elements.

LeetCode's version does this in place on an array and returns the new
length `k`; the natural functional shape is to return the filtered list
directly — its length is `k`.

Constraints: `0 <= nums.length <= 100`, values in `[0, 100]`.
