# 83. Remove Duplicates from Sorted List

[LeetCode problem 83](https://leetcode.com/problems/remove-duplicates-from-sorted-list/)

- **Difficulty**: easy
- **Tags**: linked-list

## Description

Given the head of a sorted linked list, delete all duplicates such that each
element appears only once. Return the linked list, still sorted.

Constraints: the list has between 0 and 300 nodes, values in
`[-100, 100]`, sorted in ascending order.
