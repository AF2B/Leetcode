# 2. Add Two Numbers

[LeetCode problem 2](https://leetcode.com/problems/add-two-numbers/)

- **Difficulty**: medium
- **Tags**: linked-list, math, recursion

## Description

You are given two non-empty lists representing two non-negative integers.
The digits are stored in reverse order (least significant digit first), and
each of their nodes contains a single digit. Add the two numbers and return
the sum as a list of digits in the same reverse order.

Constraints: each list has between 1 and 100 nodes, digits are in `[0, 9]`,
and neither number has a leading zero (except the number `0` itself).
