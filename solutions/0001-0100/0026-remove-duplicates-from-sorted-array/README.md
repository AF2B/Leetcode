# 26. Remove Duplicates from Sorted Array

[LeetCode problem 26](https://leetcode.com/problems/remove-duplicates-from-sorted-array/)

- **Difficulty**: Easy
- **Tags**: array, two-pointers

## Description

Given a sorted array `nums`, remove the duplicates in place so each unique
element appears once, keeping the relative order, and return the number of
unique elements. The first `k` elements of `nums` must hold the result.
