# 26. Remove Duplicates from Sorted Array

[LeetCode problem 26](https://leetcode.com/problems/remove-duplicates-from-sorted-array/)

- **Difficulty**: easy
- **Tags**: array, two-pointers

## Description

Given an integer array `nums` sorted in ascending order, remove the
duplicates in place such that each unique element appears only once.
LeetCode's version mutates the array and returns the new length `k`; the
functional shape returns the deduplicated list directly — its length is
`k`.

Constraints: `1 <= nums.length <= 3 * 10^4`, sorted in non-decreasing order.
