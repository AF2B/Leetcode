# 21. Merge Two Sorted Lists

[LeetCode problem 21](https://leetcode.com/problems/merge-two-sorted-lists/)

- **Difficulty**: easy
- **Tags**: linked-list, recursion

## Description

Merge two sorted linked lists and return it as one sorted list, by splicing
together the nodes of the two lists.

Constraints: each list has between 0 and 50 nodes, values in `[-100, 100]`,
both sorted in ascending order.
