# 58. Length of Last Word

[LeetCode problem 58](https://leetcode.com/problems/length-of-last-word/)

- **Difficulty**: easy
- **Tags**: string

## Description

Given a string `s` consisting of words and spaces, return the length of the
last word in the string. A word is a maximal substring consisting of
non-space characters only.

Constraints: `1 <= s.length <= 10^4`, `s` consists of English letters and
spaces, and `s` contains at least one word.
