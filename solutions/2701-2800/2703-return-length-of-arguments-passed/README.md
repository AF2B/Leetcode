# 2703. Return Length of Arguments Passed

[LeetCode problem 2703](https://leetcode.com/problems/return-length-of-arguments-passed/)

- **Difficulty**: easy
- **Tags**: javascript

## Description

Write a function that returns the count of arguments passed to it. The
original problem is JavaScript-specific — it exists to exercise a variadic
`arguments` object holding values of any type. OCaml has no variadic
functions or heterogeneous arrays; the closest faithful shape is a
polymorphic list, which plays the same role `arguments` does: a single
collection of values of one (possibly parametric) type, whose length is the
answer.
