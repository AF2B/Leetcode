# 1108. Defanging an IP Address

[LeetCode problem 1108](https://leetcode.com/problems/defanging-an-ip-address/)

- **Difficulty**: easy
- **Tags**: string

## Description

Given a valid IPv4 address, return a defanged version of that address — a
defanged IP address replaces every `.` with `[.]`.

Constraints: `address` is a valid IPv4 address.
