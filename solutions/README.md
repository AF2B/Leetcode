# Solutions

Problems live here, grouped in ranges of 100 (`0001-0100`, `0101-0200`, ...) so the
folder stays browsable well past problem #3000.

```
solutions/0001-0100/0001-two-sum/
  README.md          # problem summary, tags, complexity per approach
  optimized/
    solution.hpp
    solution.cpp
    test.cpp
  brute-force/
  oop/
  functional/
  design-patterns/
```

Only `optimized/` is required for a problem to be considered solved; the other
approaches are added incrementally. See [../CONTRIBUTING.md](../CONTRIBUTING.md)
for the full convention and `../scripts/new_problem.sh` to scaffold a new one.
