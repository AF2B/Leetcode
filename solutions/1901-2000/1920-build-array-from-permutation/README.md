# 1920. Build Array from Permutation

[LeetCode problem 1920](https://leetcode.com/problems/build-array-from-permutation/)

- **Difficulty**: easy
- **Tags**: array, simulation

## Description

Given a zero-based permutation `nums`, build an array `ans` where
`ans[i] = nums[nums[i]]`.

Constraints: `1 <= nums.length <= 1000`, `nums` is a permutation of
`0..nums.length - 1`.
